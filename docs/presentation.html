Mandatory foundation. PostGIS 3.4 spatial database serving as the single source of truth for all camera metadata, health status, and GIS geo-queries.

Fulfills the mandatory Model 1 foundation, implements the exact adapter principles demanded in the Problem Statement, qualifies for the explicit Bonus Category for innovative hybrid architecture, and avoids the cost/fragility of a monolithic Model 4 centralization.

System Design & Justification Slide 3 / 8
Streaming Engineering

Strict Sentinel Protocol Implementation

Protocol Compliance

✅ Mandatory RTSP over TCP

Enforced across all clients (rtsp_transport=tcp). Eliminates UDP packet drops across firewalls and NAT that mimic AI bugs.

✅ PTS Monotonic Timing Anchor

Timing driven exclusively by Presentation Timestamp (CAP_PROP_POS_MSEC). Eliminates impossible vehicle velocities caused by GOP buffer replays.

✅ Exponential Backoff Reconnection

Auto-reconnects with backoff (2.0s initial, 1.5x multiplier, capped at 30.0s). Never floods network with tight retry loops.

✅ Loop-Cut Scene Discontinuity Recovery

Detects backward PTS steps in looped test feeds, re-anchors the timing clock, and flushes transient trackers cleanly without crashing.

Committed YOLOv8 ANPR & Concurrency Control

Deep Learning Pipeline

🎯 YOLO-Only Detection

No fragile classical edge/contour methods. Ultralytics YOLOv8 vehicle detection + license plate localization trained on Indian vehicle types.

🔤 Positional OCR Cleaning

Corrects character ambiguities based on Indian registration syntax: [A-Z]{2}[0-9]{1,2}[A-Z]{1,3}[0-9]{4} (e.g. O → 0 in numbers).

⚡ 50-Stream Concurrency

PTS-delta frame throttling samples each camera at 1.5 FPS (75 FPS total load), handled effortlessly by an 8-worker pool with backpressure queues.
